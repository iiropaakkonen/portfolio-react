
# Portfolio
https://iiro-paakkonen.vercel.app

My personal portfolio site, written from scratch with React, TypeScript and Tailwind CSS and hosted on Vercel. It has an intro, a scrolling band of technologies I use, project cards and my contact links.

## Built with

- React and TypeScript, bundled with Vite
- Tailwind CSS for styling
- Vercel for hosting

## Decisions

- **Dark mode:** A very personal decision to have a dark mode and to have the page remember the user's choice.
- **Technology band:** a pure CSS animation to showcase all the technologies I use or can use.
- **Projects:** Cards showcasing projects I have built or have been a part in developing.
